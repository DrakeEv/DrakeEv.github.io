# Drake Everett — IT & Cybersecurity Portfolio

A single-page personal portfolio site showcasing my background in IT support,
networking, and cybersecurity. It includes an about section, a skills breakdown
(IT support, networking, cybersecurity, and development), featured projects, and
contact information. Built as a static site with a responsive nav menu and
smooth-scroll "back to top" button.

## Key Features

- **Responsive navigation** — collapsible mobile menu, smooth in-page scrolling
- **Skills overview** — IT support, networking, cybersecurity, and development
  skills organized into cards
- **Projects showcase** — highlights hands-on work (PC builds, cybersecurity
  network labs, a C++/SFML jigsaw puzzle game, Linux Mint setup)
- **Back-to-top button** that appears on scroll
- **Contact section** with email and LinkedIn links

## Tech Stack

- HTML, CSS, vanilla JavaScript (no frameworks or build tools)
- Hosted via GitHub Pages

## Running Locally

No installation needed — just open the file in a browser:

```bash
# from the repo directory
start index.html   # Windows
# or open index.html   # macOS
```
